## 一、開發目的

1. 做出一個**實用的**凱薩加密／解密工具。
2. 用**可拖曳的密碼盤**把「位移」的概念畫出來，比只有文字框的工具更好懂。
3. 加入**步驟展示、破解挑戰**，讓使用者一邊玩一邊學會原理，也知道它為什麼不安全。
4. 練習用 Vibe Coding 的流程（和 AI 討論需求 → 寫規格書 → 產生程式 → 上傳發佈）完成作品。

## 四、核心演算法

### 4.1 凱薩位移

字母編號：A = 0、B = 1、…、Z = 25

```
加密：E(x) = (x + K) mod 26
解密：D(x) = (x − K) mod 26
```

### 4.2 正確的取模
JavaScript 的 `%` 遇到負數會得到負值（例如 `-1 % 26 = -1`），所以改用：
```
mod(n, m) = ((n % m) + m) % m
```

### 4.3 頻率分析（暴力破解的 ⭐ 判斷）
- 先統計解密後文字中每個字母出現幾次。
- 再和英文字母的標準頻率（E 12.7%、T 9.1%…）做**卡方檢定**。
- 卡方值最小的 K，就判定為最像英文的答案。

### 4.4 轉盤角度
- 每個字母佔 `360 / 26 ≈ 13.85°`。
- 位移量為 K 時，內圈逆時針轉 `K × 13.85°`。
- 從 25 變成 0 這種情況，會走**最短路徑**，不會整圈轉回去。

## 五、操作流程

### 流程 A：加密一段文字
1. 開啟網頁，預設是「加密」模式、K = 3。
2. 在「輸入文字」框輸入英文。
3. 拖曳轉盤、拉滑桿或在數字框輸入位移量。
4. 「輸出結果」即時顯示密文（有翻轉動畫）。
5. 按「📋 複製結果」把密文複製起來。

### 流程 B：解密一段文字
1. 按「🔓 解密」。
2. 貼上密文，設定已知的位移量。
3. 輸出區顯示明文。
4. 如果不知道位移量 → 往下看「暴力破解」，點有 ⭐ 的那一列。

### 流程 C：分享暗號給朋友
1. 在加密模式輸入原文。
2. 決定要不要勾選「連結附上位移量」。
3. 按「🔗 產生分享連結」→ 連結自動複製，並顯示在下方。
4. 朋友打開連結：
   - **有附位移量** → 自動切換到解密模式並顯示原文。
   - **沒附位移量** → 自動切換到解密模式並跳出提示，引導朋友用暴力破解。

### 流程 D：破解挑戰
1. 系統從名言庫隨機挑一句，用隨機的 K（1–25）加密。
2. 使用者拉「猜 K」滑桿，下方即時預覽解密結果。
3. 覺得預覽像正常英文時，按「✔ 送出答案」。
4. 答對 → 顯示原文，噴出彩帶，計分 +1。答錯 → 顯示鼓勵訊息。
5. 可以按「💡 提示」（第 1 次給第一個字母，第 2 次給 K 的範圍）。
6. 按「⏭ 下一題」換題。

### 流程 E：步驟展示
1. 輸入一個英文字母，按「▶ 開始展示」。
2. 5 個步驟每隔 0.6 秒依序滑出。
3. 轉盤上同時亮起「原字母」和「結果字母」。

### 6.4 密碼盤規格（SVG，畫布 420 × 420）

| 部件 | 半徑 | 說明 |
|---|---|---|
| 外圈 | 160–205 | 明文 A–Z，固定不動 |
| 內圈 | 110–158 | 密文 A–Z，依 K 旋轉，有 0.35 秒的轉動動畫 |
| 中心圓 | 110 | 大字顯示目前的 K 值，下方標示「SHIFT · 位移量」 |
| 紅色指標 | 正上方 | 指出外圈 A 對應到內圈哪個字母 |

### 6.5 動畫與回饋

| 動畫 | 觸發時機 | 時間 |
|---|---|---|
| 字母翻轉 | 輸出字元有改變時 | 0.45 秒，逐字延遲 |
| 轉盤旋轉 | K 值改變時 | 0.35 秒 |
| 步驟滑入 | 按「開始展示」 | 每步間隔 0.6 秒 |
| 彩帶 | 破解挑戰答對時 | 約 3 秒，150 片 |
| Toast 提示 | 複製、分享、套用等操作 | 2.2 秒後自動消失 |

### 6.6 響應式設計（RWD）
- 螢幕寬度 > 820px：轉盤在左、操作區在右（左右兩欄）。
- 螢幕寬度 ≤ 820px（手機）：轉盤在上、操作區在下（單欄）。
- 轉盤設定 `touch-action: none`，支援手指拖曳。

## 八、例外情況處理

| 編號 | 情況 | 處理方式 |
|---|---|---|
| E01 | 輸入框是空的 | 輸出區顯示灰色提示「結果會顯示在這裡…」；暴力破解顯示「請先在上方輸入密文」 |
| E02 | 輸入中文、數字、標點、emoji | 原樣保留不轉換 |
| E03 | 輸入多行文字 | 保留換行 |
| E04 | 數字框輸入負數或超過 25 | 自動取模，例如 -1 → 25、29 → 3 |
| E05 | 數字框輸入非數字或留空 | 視為 0 |
| E06 | 步驟展示輸入的不是英文字母 | 顯示「請輸入一個英文字母 A~Z」，不執行展示 |
| E07 | 沒有內容時按「複製結果」 | 提示「沒有內容可以複製」 |
| E08 | 瀏覽器不支援 Clipboard API，或在 `file://` 下被擋 | 改用舊的 `execCommand('copy')` 方法 |
| E09 | 沒有內容時按「分享連結」 | 提示「請先輸入文字」 |
| E10 | 分享連結沒有附位移量 | 收到連結時設 K = 0，並提示使用者往下用暴力破解 |
| E11 | 分享連結的 `k` 參數不正確 | 用 `parseInt` 加取模處理，無效值視為 0 |
| E12 | 破解挑戰答對後又按「送出」 | 不重複計分，提示「按下一題繼續」 |
| E13 | 提示按了 2 次以上 | 一直顯示第 2 個提示（K 的範圍），不會出錯 |
| E14 | 輸入的文字本身就是英文（最佳 K = 0） | 暴力破解清單不標 ⭐（建議改進：顯示「可能還沒加密」的提示） |
| E15 | 拖曳轉盤停在兩格之間 | 放開後自動對齊最近的格子 |
| E16 | K 從 25 變成 0 | 轉盤走最短路徑，不會整圈轉 |
| E17 | 使用者輸入 HTML 標籤（如 `<script>`） | 一律用 `textContent` 顯示，防止 HTML 注入 |
| E18 | 直接用 `file://` 開啟時使用分享連結 | 連結只在自己的電腦有效；要上傳 GitHub Pages 才能分享給別人 |

## 十、修改過程分享

### 第 1 輪：修正網頁空白、按鈕沒反應
- **我的要求**：網頁左邊是空的，按鈕都沒有反應，請檢查並修正。
- **AI 的發現**：AI 產生的程式碼在中途被截斷，檔案只有 HTML 和 CSS，缺少整段 JavaScript。
- **AI 的修改**：補上 JavaScript 前半段（常數、加密演算法、畫轉盤、拖曳轉盤）。
- **前後差異**：修改前左邊空白、按鈕沒反應；修改後轉盤有出現，但程式仍未完整。

### 第 2 輪：補完 JavaScript 後半段
- **我的要求**：請檢查這是不是完整版並修正。
- **AI 的發現**：檔案停在沒有結尾的註解 `/* ---------- 5. 設定位移`，也沒有 `</script>`，造成整段程式無法執行。
- **AI 的修改**：補上第 5～15 段，包含位移量同步、模式切換、翻轉動畫輸出、字母對照表、暴力破解與頻率分析、步驟展示、破解挑戰、彩帶特效、複製、分享連結、深色模式。
- **前後差異**：修改前功能全部失效；修改後 6 個功能區塊都能使用。

### 第 3 輪：清除重複文字
- **我的要求**：再次貼上程式碼請 AI 檢查。
- **AI 的發現**：「為什麼它不安全？」的說明重複出現兩次（舊的半句沒刪掉）。
- **AI 的修改**：指出要刪掉沒寫完的半句，只保留完整的一句。
- **前後差異**：修改前網頁上同一段文字重複；修改後只剩一句。
